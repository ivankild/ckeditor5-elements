CKEditor 5 Elements – full example

Documentation GitHub
  • Right-click a block, or press Shift+F10: its menu.
  • Put the cursor in a note or a heading: its floating toolbar.
  • Click a breadcrumb: the menu of that element.
  • Click the frame of a note, a tip or a step: it is selected as a whole.
  • Alt+Enter (⌥ Enter on macOS): quick insert.
  • Alt+F10: the toolbars; Alt+0: all keystrokes.
  • The editor is in the browser console.
